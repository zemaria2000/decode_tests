## Optimisations

This folder comprises the results for all optimisations conducted in all possible scenarios.  

Each folder is of type `"<dataset_name>_<model_name>"`, and it comprises two files:  
* `opt_results.csv`: csv file with all optimisation attempts, including hyperparameter values, evaluation function information, and optimisation score.
* `hyperparams.yaml`: yaml file with the best hyperparameters (the ones that maximised the optimisation score), and that are used in testing of the models
