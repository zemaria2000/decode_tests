## Datasets

This folder includes four of the five datasets that were used for testing under this repository. The fifth (penguins) was directly downloaded from the Kaggle API. Below is a table, available in the paper, briefly summarising each dataset.


| Dataset            | Type | # samples | # features<br>(total / num. / cat.) | Outputs        |
|--------------------|------|-----------|--------------------------------------|----------------|
| **[Hawks](https://rdrr.io/rforge/Stat2Data/man/Hawks.html)**   | clf  | 891       | 8 / 6 / 2                            | 3 classes      |
| **[Penguins](https://www.kaggle.com/datasets/larsen0966/penguins)**| clf  | 333       | 7 / 4 / 3                            | 3 classes      |
| **[Mushrooms](https://www.kaggle.com/code/nicktp/mushroom-classification-with-r)**| clf | 8124      | 22 / 0 / 22                          | 2 classes      |
| **[Housing](https://www.kaggle.com/datasets/vikrishnan/boston-house-prices)**| reg | 506        | 13 / 12 / 1                          | 1 num. output  |
| **[Diamonds](https://www.kaggle.com/datasets/shivam2503/diamonds)**| reg | 53905     | 9 / 6 / 3                            | 1 num. output  |
